# 技术支持

如果您在使用本应用过程中遇到任何问题，或有建议和反馈，欢迎通过以下方式联系我们。

## 联系方式

- **邮箱**：<app-support@udnz.com>
- **网站**：[https://udnz.github.io/schoolsmap-web](https://udnz.github.io/schoolsmap-web/)

## 服务时间

- **在线支持**：周六、周日（中国大陆）22:00–24:00

## 常见问题

### 如何取消订阅？

打开 **系统设置 > Apple ID > 订阅**，选择本应用订阅，点击 **取消订阅**。取消后仍可享受服务至当前订阅周期结束。

### 数据来源是什么？

- **学区数据**：深圳市政府数据开放平台
- **地址数据**：深圳市标准地址服务平台
- **地图服务**：高德地图
